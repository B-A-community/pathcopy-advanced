# PathCopy Advanced

Плагин SketchUp 2024 для копирования групп и компонентов вдоль траектории —
замена старому PathCopy от Smustard, который не обновлялся с 2014 года.

Версия 0.2.0 · лицензия [Apache 2.0](LICENSE) · © 2026 B&A community

Создатели: [maksarsanjeev](https://github.com/maksarsanjeev) — см. [AUTHORS](AUTHORS).

## Что делает

Кликаете по ребру — это путь. Кликаете по группе или компоненту — это то, что
копируется. Дальше меняете что угодно, копии перестраиваются на месте.

**Путь не надо сваривать.** Цепочка отдельных рёбер обходится сама: от кликнутого
ребра плагин идёт по соседям, пока у вершины ровно два ребра, и останавливается
на любой развилке вместо того, чтобы угадывать. Контур грани, дуга, окружность,
замкнутый контур — всё одинаково. Выделили несколько разрозненных цепочек
заранее — получите несколько путей за один проход.

**Четыре способа расставить:**

| Режим | Что делает |
|---|---|
| Spacing | Фиксированный шаг; остаток длины отрабатывается выравниванием от начала, по центру или от конца |
| Count | Ровно N копий, равномерно |
| Fit spacing | Ближайший к заданному шаг, который делит путь нацело |
| Vertices | По одной копии на каждый узел пути |

Плюс отступы от начала и конца. На замкнутом контуре замыкающая копия не
дублирует первую.

**Три ориентации:** по азимуту, как в оригинале; полная 3D-касательная с учётом
уклона; без поворота вообще. На вертикальном отрезке азимут не вырождается —
держится предыдущий. На замкнутом контуре можно выбрать, куда смотрят копии —
**наружу или внутрь** — независимо от того, в какую сторону контур нарисован;
любой путь можно развернуть. Точка привязки к пути — origin объекта, центр габаритов или
низ габаритов. Сверху — доворот на угол, смещение вбок и по высоте в системе
координат пути, разворот каждой второй копии.

**Разброс** — случайные поворот, масштаб и смещение в заданных пределах,
воспроизводимые по seed. `Ctrl`+клик добавляет второй, третий объект — копии
начинают чередоваться, каждый со своей трансформацией.

**Копии наследуют** материал, тег, имя и настройки теней источника. Компонент с
масштабом ×2 выходит ×2 — оригинал это терял. Опционально всё складывается в
группу и получает свой тег.

**Один Undo на всю сессию.** Первая постановка открывает обычную операцию, каждая
правка — прозрачную, которая в неё сливается. Оригинал дёргал `Sketchup.undo`
и мог откатить чужую работу.

## Управление

| Ввод | Действие |
|---|---|
| Клик по ребру или грани | Путь. Или выделить рёбра до запуска инструмента |
| Клик по группе/компоненту | Объект. `Ctrl`+клик добавляет ещё |
| `48` | Шаг между копиями (в единицах модели) |
| `20x` | Ровно 20 копий |
| `0` | Режим «по вершинам» |
| `Tab` | Цикл режима распределения |
| `↑` `↓` | Цикл ориентации |
| `←` `→` | Цикл выравнивания |
| `F` | Замкнутый контур: как нарисовано / наружу / внутрь |
| `R` | Развернуть направление пути |
| `Esc` | Шаг назад; сначала убирает поставленные копии |
| ПКМ | Все настройки: смещения, разброс, тег, привязка |

Превью рисуется до клика: подсвеченный путь, маркеры точек и габаритные рамки
копий. Настройки запоминаются между сессиями.

## Статус

**0.2.0 — тестовая сборка. Релиза нет, готовый пакет не выкладывается.**
Пакет собирается локально и раздаётся напрямую тем, кто тестирует. Что сделано
и что осталось — в [CHANGELOG.md](CHANGELOG.md).

Проверено на SketchUp 2024 (24.0.484): 80 офлайн-тестов геометрии и 111 живых
проверок в работающем SketchUp, включая реальный пикинг мышью через
`PickHelper`. Что именно — см. «Проверка».

На SketchUp 2025 не прогонялся. Версионных зависимостей в коде нет — тот же
Ruby 3.2, только стабильный API; нижняя граница по синтаксису — SketchUp 2019
(Ruby 2.5).

## Установка

Собрать пакет (см. «Сборка») и поставить его: SketchUp → **Расширения →
Менеджер расширений → Установить расширение**. Пункт появится в
**Расширения → PathCopy Advanced**, панель инструментов — в **Вид → Панели
инструментов → PathCopy Advanced**. После установки SketchUp нужно
перезапустить — Ruby-файлы кешируются.

Сборка не подписана: в **Менеджер расширений → Настройки** политика загрузки
должна быть «Неограниченная» или «Утверждать неопознанные расширения».

Для разработки `.\dev_install.ps1` копирует `src\` прямо в папку Plugins
SketchUp 2024; для другой версии — `.\dev_install.ps1 -Version 2025`.

## Структура

```
src/
  pathcopy_advanced.rb             регистратор расширения
  pathcopy_advanced/
    main.rb                        точка сборки, меню, панель
    constants.rb                   версия, допуски, лимиты, перечисления
    path.rb                        полилиния с параметризацией по длине дуги
    path_builder.rb                entities → упорядоченные цепочки
    distribution.rb                где стоят копии, в координате длины
    placement.rb                   длины → мировые трансформации
    copier.rb                      создание сущностей, undo
    settings.rb                    опции и их сохранение между сессиями
    menus.rb                       контекстное меню и диалоги
    tool.rb                        инструмент: превью, поле измерений, клавиши
    icons/                         *.svg (Windows) + *.png (фолбэк), курсор
    instructor/index.html          панель Instructor
tests/
  sketchup_stub.rb                 заглушка API для запуска без SketchUp
  run_tests.rb, test_*.rb          офлайн-тесты
  live_*.rb                        живые проверки внутри SketchUp
tools/
  build_icons.ps1                  перерисовывает PNG-фолбэки иконок
  build_rbz.ps1                    собирает src/ в build/PathCopyAdvanced-<версия>.rbz
(пакет собирается локально, в репозиторий не кладётся)
```

Пространство имён — `BACommunity::PathCopyAdvanced`.

## Сборка

```bash
powershell -ExecutionPolicy Bypass -File "tools\build_rbz.ps1"
```

Версия читается из `src/pathcopy_advanced/constants.rb`, пакет ложится в
`build/PathCopyAdvanced-<версия>.rbz`. Иконки перерисовываются отдельно, только
если менялись формы:

```bash
powershell -ExecutionPolicy Bypass -File "tools\build_icons.ps1"
```

## Проверка

Два уровня. Геометрическое ядро не зависит от живой модели, поэтому гоняется
обычным Ruby 3.2 через заглушку API:

```bash
ruby tests/run_tests.rb
```

То, за что заглушка не отвечает — порядок композиции трансформаций, `Group#copy`,
вложенность undo-операций, пикинг, меню — проверяется скриптами `tests/live_*.rb`
в работающем SketchUp. Каждый пишет отчёт в `build/*_result.txt`, потому что
`load` через Ruby-консоль или мост возвращает `true`, а не значение скрипта.

| Скрипт | Что проверяет |
|---|---|
| `live_test.rb` | Пути, распределение, ориентация, привязка, один Undo, запуск инструмента |
| `live_recheck.rb` | Масштаб, привязка по габаритам, наследование материала и тега, группировка, чередование |
| `live_interact.rb` | Поле измерений, `12x`, стрелки, `Tab`, `Esc`, Undo |
| `live_pick.rb` | Реальный пикинг через `view.screen_coords` → `onLButtonDown`, `Ctrl`+клик |
| `live_misc.rb` | Контекстное меню, сохранение настроек, разрешение иконок |
| `live_facing.rb` | Наружу/внутрь на двух окружностях, ручной контур по часовой, клавиши `F` и `R`, рендер |
| `live_scene.rb` | Строит демо-сцену и рендерит её в `build/` |

## Откуда это взялось

Оригинал — PathCopy 2.200 Рика Уилсона (Smustard, 2014): один класс на 461
строку, путь только из одного ребра или одной `Curve`, компонент терял
масштаб, Undo через `Sketchup.undo`, шаг 0.001 вешал SketchUp намертво. Разбор
по пунктам — в [AUDIT.md](AUDIT.md). Код оригинала под Smustard EULA
(«All Rights Reserved»), поэтому здесь написано с нуля и в репозиторий не
входит.

## Грабли

- `.rbz` — обычный ZIP, `pathcopy_advanced.rb` должен лежать **в корне**
  архива, а пути внутри — через прямой слэш (см. комментарий в `build_rbz.ps1`).
- SVG-иконки понимает только Windows-версия SketchUp (2016+); на macOS нужен
  PDF, поэтому там код откатывается на PNG.
- Равномерный масштаб SketchUp хранит в w-члене матрицы: `xaxis.length` у
  масштабированного инстанса всегда 1, смотреть надо `xscale`.
- Поле измерений читает значение в единицах модели: `200` в миллиметровой
  модели — это 200 мм, а не 200 дюймов.
