# PathCopy Advanced — копирование вдоль пути для SketchUp 2024 / 2025

**Русский** · [English](README.en.md)

Плагин SketchUp: копирует группы и компоненты вдоль траектории и протягивает
по ней профиль-поручень. Замена старому PathCopy от Smustard, который не
обновлялся с 2014 года.

Версия 1.0 · лицензия [Apache 2.0](LICENSE) · © 2026 B&A community

Создатели: [maksarsanjeev](https://github.com/maksarsanjeev) — см. [AUTHORS](AUTHORS).

Два пакета: русский и английский. Язык зашит в сборку, переключать в
интерфейсе нечего.

## Как пользоваться

1. Кликните ребро — это путь. Соединённые рёбра подхватываются сами,
   `Weld` не нужен. Клик по грани берёт её контур; `Ctrl`+клик
   (`Option` на macOS) добавляет ещё один путь.
2. Кликните группу или компонент — его копируем. `Ctrl`+клик добавляет
   ещё объекты, копии начинают чередоваться.
3. Дальше меняйте что угодно в панели настроек — копии перестраиваются
   на месте, вся сессия остаётся **одним шагом отмены**.

## Что умеет

**Путь.** Цепочка несваренных рёбер обходится сама: от кликнутого ребра
плагин идёт по соседям, пока у вершины ровно два ребра, и останавливается на
развилке вместо того, чтобы угадывать. Контур грани, дуга, окружность,
замкнутый контур — одинаково. Несколько путей за один проход.

**Расстановка.**

| Режим | Что делает |
|---|---|
| Шаг | Фиксированное расстояние; остаток отрабатывается выравниванием от начала, по центру или от конца |
| Количество | Ровно N копий, равномерно |
| Подгонка шага | Ближайший к заданному шаг, который делит путь нацело |
| Подгонка по сегментам | Копия в каждой вершине, шаг подгоняется внутри каждого сегмента — режим для ограждений |
| По вершинам | По одной копии на каждый узел пути |

Плюс отступы от начала и конца. На замкнутом контуре замыкающая копия не
дублирует первую.

**Ориентация.** По азимуту; полная 3D-касательная с учётом уклона; по
плоскости пути (контур на стене несёт копии в плоскости стены); без поворота.
В вершине копия берёт направление уходящего сегмента — столб в углу стоит по
рельсу, а не по биссектрисе; на плавных изломах касательная усредняется.
На замкнутом контуре копии можно развернуть **наружу или внутрь** независимо
от того, в какую сторону он нарисован. Кнопки **«Вдоль» / «Поперёк»** ставят
объект вдоль или перпендикулярно линии.

**Поручень.** Профиль вдоль того же пути: прямоугольный или круглый, своя
ширина и высота, привязка по центру линии либо целиком наружу или внутрь,
подъём над путём (поручень поверх стоек) и продление за концы. Углы режутся
митрой, поэтому поворот проходит одной деталью без щелей.

**Доводка руками.** Клик по уже поставленной копии доворачивает её на
заданный угол, `Shift`+клик — обратно. Доворот переживает любую перестройку.

**Разброс.** Случайные поворот, масштаб и смещение в заданных пределах,
воспроизводимые по зерну.

**Результат.** Копии наследуют материал, тег, имя и настройки теней
источника; компонент сохраняет свой масштаб и поворот. Опционально всё
складывается в группу и получает заданный тег.

## Управление

| Ввод | Действие |
|---|---|
| Клик по ребру или грани | Путь. `Ctrl`+клик (`Option` на Mac) добавляет ещё один |
| Клик по группе/компоненту | Объект. `Ctrl`+клик добавляет ещё |
| Клик по поставленной копии | Доворот; `Shift`+клик — обратно |
| `48` | Шаг между копиями, в единицах модели |
| `20x` | Ровно 20 копий |
| `0` | Режим «по вершинам» |
| `Tab` | Цикл режима расстановки |
| `↑` `↓` | Цикл ориентации |
| `←` `→` | Цикл остатка шага |
| `Esc` | Шаг назад; сначала убирает поставленные копии |
| ПКМ | То же, что в панели |

Буквенных клавиш у инструмента нет намеренно: в SketchUp одиночная буква
всегда уходит шорткату пользователя (`R` — прямоугольник), а не инструменту.

Превью рисуется до клика: подсвеченный путь, маркеры точек, габаритные рамки
копий и каркас поручня. Настройки запоминаются между сессиями.

## Установка

Скачать из [релиза](https://github.com/B-A-community/pathcopy-advanced/releases/latest)
архив своего языка — `pathcopy-advanced-1.0.0-rus.zip` или `-eng.zip`. Внутри
плагин `.rbz` и одностраничная PDF-инструкция. Плагин поставить: SketchUp → **Расширения → Менеджер расширений →
Установить расширение**. Инструмент и кнопка панели появятся в
**Расширения → PathCopy Advanced**, панель инструментов — в **Вид → Панели
инструментов → PathCopy Advanced**. После установки SketchUp нужно
перезапустить — Ruby-файлы кешируются.

Сборка не подписана: в **Менеджер расширений → Настройки** политика загрузки
должна быть «Неограниченная» или «Утверждать неопознанные расширения».

Для разработки `.\dev_install.ps1` копирует `src\` прямо в папку Plugins
SketchUp 2024; для другой версии — `.\dev_install.ps1 -Version 2025`.

```
  pathcopy_advanced/

    lang.rb                        строки Ruby-части: ru + en
    constants.rb                   версия, допуски, лимиты, списки режимов
    path.rb                        полилиния с параметризацией по длине дуги
    path_builder.rb                entities → упорядоченные цепочки
    distribution.rb                где стоят копии, в координате длины
    placement.rb                   длины → мировые трансформации
    railing.rb                     поручень: профиль, срез митрой, обшивка
    copier.rb                      создание сущностей, undo
    settings.rb                    опции и их сохранение между сессиями
    panel.rb                       панель настроек (HtmlDialog)
    about.rb                       окно «О плагине»
    menus.rb                       контекстное меню и диалоги
    tool.rb                        инструмент: превью, поле измерений, клавиши
    html/                          panel.html, about.html, i18n.js (ru + en), ba.css, ba.js
    icons/                         *.svg (Windows) + *.png (фолбэк), курсор
    instructor/ru, instructor/en   панель Instructor на двух языках
docs/                              инструкция: guide-rus.html / guide-eng.html и PDF
tests/                             офлайн-тесты и живые сценарии

(пакеты собираются локально в dist/, в репозиторий не кладутся)
```

Пространство имён — `BACommunity::PathCopyAdvanced`.

## Сборка

```bash
powershell -ExecutionPolicy Bypass -File "tools\build_rbz.ps1"
```

Собирает оба пакета в `dist/`. Отдельный язык — `-Lang ru` или `-Lang en`.
Языковой пакет — тот же исходник: в копии подменяется строка `LANG` в
`lang.rb` (Ruby) и `html/i18n.js` (окна). Версия читается из `constants.rb`.

Релизные архивы — как у area counter: `toolsuild_guides.ps1` печатает
`docs\guide-*.html` в PDF через headless Chrome или Edge, затем
`toolsuild_rbz.ps1 -Release` кладёт рядом с пакетами
`dist\pathcopy-advanced-<версия>-rus.zip` / `-eng.zip` — плагин плюс инструкция.

```bash
powershell -ExecutionPolicy Bypass -File "toolsuild_guides.ps1"
powershell -ExecutionPolicy Bypass -File "toolsuild_rbz.ps1" -Release
```

Иконки перерисовываются отдельно, только если менялись формы:

```bash
powershell -ExecutionPolicy Bypass -File "tools\build_icons.ps1"
```

## Проверка

Два уровня. Геометрическое ядро не зависит от живой модели, поэтому гоняется
обычным Ruby 3.2 через заглушку API:

```bash
ruby tests/run_tests.rb
```

То, за что заглушка не отвечает — порядок композиции трансформаций,
`Group#copy`, вложенность undo-операций, пикинг, меню, панель — проверяется
скриптами `tests/live_*.rb` в работающем SketchUp. Каждый пишет отчёт в
`build/*_result.txt`, потому что `load` через Ruby-консоль или мост
возвращает `true`, а не значение скрипта.

| Скрипт | Что проверяет |
|---|---|
| `live_test.rb` | Пути, расстановка, ориентация, привязка, один Undo, запуск инструмента |
| `live_recheck.rb` | Масштаб, привязка по габаритам, наследование материала и тега, группировка, чередование |
| `live_interact.rb` | Поле измерений, `12x`, стрелки, `Tab`, `Esc`, Undo |
| `live_pick.rb` | Реальный пикинг через `view.screen_coords` → `onLButtonDown`, `Ctrl`+клик |
| `live_misc.rb` | Контекстное меню, сохранение настроек, разрешение иконок |
| `live_facing.rb` | Наружу/внутрь на двух окружностях, ручной контур по часовой, рендер |
| `live_fence.rb` | Прямоугольник с посторонней линией в углу: столб в каждом углу, все по рельсу; второй путь `Ctrl`+кликом |
| `live_railing.rb` | Поручень: солид, срез на углах, привязка, продление, замкнутый контур; доворот копии кликом |
| `live_scene.rb` | Строит демо-сцену и рендерит её в `build/` |

Версия 1.0 прогнана на **обоих** языковых пакетах: 118 офлайн-тестов и
157 живых проверок на каждом, SketchUp 2024 (24.0.484).

## Откуда это взялось

Оригинал — PathCopy 2.200 Рика Уилсона (Smustard, 2014): один класс на 461
строку, путь только из одного ребра или одной `Curve`, компонент терял
масштаб, Undo через `Sketchup.undo`, шаг 0.001 вешал SketchUp намертво.
Разбор по пунктам — в [AUDIT.md](AUDIT.md). Код оригинала под Smustard EULA
(«All Rights Reserved»), поэтому здесь написано с нуля и в репозиторий он не
входит.

## Грабли

- `.rbz` — обычный ZIP, `pathcopy_advanced.rb` должен лежать **в корне**
  архива, а пути внутри — через прямой слэш (см. комментарий в `build_rbz.ps1`).
- SVG-иконки понимает только Windows-версия SketchUp (2016+); на macOS нужен
  PDF, поэтому там код откатывается на PNG.
- Равномерный масштаб SketchUp хранит в w-члене матрицы: `xaxis.length` у
  масштабированного инстанса всегда 1, смотреть надо `xscale`.
- Поле измерений читает значение в единицах модели: `200` в миллиметровой
  модели — это 200 мм, а не 200 дюймов.
