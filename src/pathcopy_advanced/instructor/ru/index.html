PathCopy Advanced

Шаги

  1. Кликните ребро — это путь. Соединённые рёбра подхватываются сами, сваривать не нужно. Клик по грани берёт её контур. Ctrl+клик (Option на Mac) добавляет ещё один путь; можно и выделить рёбра до запуска.
  2. Кликните группу или компонент — его копируем. Ctrl/Option+клик добавляет ещё объекты, копии будут чередоваться.
  3. Дальше меняйте что угодно в панели настроек — копии перестраиваются на месте, вся сессия остаётся одним шагом отмены.

Поле измерений

1200
Шаг между копиями, в единицах модели.
20x
Ровно 20 копий, равномерно.
0
По одной копии на каждую вершину.

Клавиши

Tab
Следующий режим: шаг, количество, подгонка, подгонка по сегментам, по вершинам.
↑ ↓
Ориентация: в плане, в 3D, по плоскости пути, не поворачивать.
← →
Куда девать остаток шага: от начала, по центру, от конца.
Esc
Шаг назад; сначала убирает поставленные копии.
Правая кнопка
То же меню, что и панель, если панель закрыта.

Режимы расстановки

  • Шаг — фиксированное расстояние, остаток по выравниванию.
  • Количество — ровно N копий на всю длину.
  • Подгонка шага — ближайший к заданному шаг, делящий путь нацело.
  • Подгонка по сегментам — копия в каждой вершине, шаг подгоняется внутри каждого сегмента. Ограждения.
  • По вершинам — по одной копии на каждый узел.

Поручень

Профиль вдоль того же пути: прямоугольный или круглый, с привязкой по центру линии либо целиком наружу или внутрь. «Поднять» выводит поручень на высоту стоек, «продлить концы» — за крайние точки. Углы срезаются митрой, поворот проходит одной деталью.

Доворот вручную

Клик по уже поставленной копии доворачивает её на заданный угол, Shift+клик — обратно. Доворот сохраняется при смене любых настроек; сбросить — кнопкой в панели.

Поперёк пути

Кнопка «Поперёк» в панели (или доворот 90°): ось X объекта встаёт перпендикулярно линии — столбики ограждения смотрят через рельс, а не вдоль него.
