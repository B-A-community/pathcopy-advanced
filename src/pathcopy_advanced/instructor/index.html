PathCopy Advanced

Steps

  1. Click an edge to use as the path. Connected edges are followed automatically — no welding required. Click a face to use its outer loop. Ctrl+click (Option on macOS) adds another path; pre-selecting edges before starting the tool works too.
  2. Click the group or component to copy. Ctrl/Option+click adds more objects, and copies then alternate between them.
  3. Keep typing values or changing options. The copies rebuild in place, and the whole session is a single undo step.

Keys

Tab
Cycle distribution: spacing, count, fit, fit per segment, vertices.
↑ ↓
Cycle orientation: flat, 3D, path plane, keep.
F
On a closed path: as drawn, face outward, face inward.
R
Reverse the path direction.
← →
Cycle alignment: start, centered, end.
Esc
Step back one stage; removes the copies first.
Right-click
Every option, including offsets and randomisation.

Modes

  • Spacing — fixed distance, leftover length handled by the alignment setting.
  • Count — a fixed number of copies, evenly spread.
  • Fit spacing — nearest spacing to the one you typed that divides the path evenly.
  • Fit per segment — a copy on every vertex, spacing fitted inside each segment. Railings and fences.
  • Vertices — one copy per corner of the path.
