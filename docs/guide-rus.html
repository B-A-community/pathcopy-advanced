PathCopy Advanced 1.0 — краткая инструкция

Плагин SketchUp 2024 / 2025: копирование групп и компонентов вдоль пути и поручень профилем по тому же пути

1Установка

SketchUp → Window → Extension Manager → Install Extension → выбрать pathcopy-advanced-1.0.0-rus.rbz → перезапустить SketchUp. Появятся две кнопки на панели «PathCopy Advanced» — инструмент и панель настроек — и меню Extensions → PathCopy Advanced. Сборка не подписана: в Extension Manager → Settings политика загрузки должна быть «Unrestricted».

2Скопировать вдоль пути

  1. Запустите инструмент. Вместе с ним откроется панель настроек.
  2. Кликните ребро — это путь. Соседние рёбра подхватываются сами, сваривать не нужно; обход останавливается на развилке. Клик по грани берёт её контур. Ctrl+клик добавляет ещё один путь, можно и выделить рёбра заранее.
  3. Кликните группу или компонент — его копируем. Ctrl+клик по нескольким объектам — копии будут чередоваться.
  4. Меняйте что угодно в панели — копии перестраиваются на месте. Вся сессия — один шаг отмены.

3Расстановка

Шагфиксированное расстояние; остаток — от начала, по центру или от конца
Количестворовно N копий на всю длину
Подгонка шагаближайший к заданному шаг, делящий путь нацело
По сегментамкопия в каждой вершине, шаг подгоняется внутри сегмента — для ограждений
По вершинампо одной копии на узел пути

В поле измерений SketchUp: 1200 — шаг в единицах модели, 20x — двадцать копий, 0 — по вершинам. Tab — следующий режим.

4Ориентация

По пути, в плане — поворот по азимуту; в 3D — с наклоном по уклону; по плоскости пути — для контура на стене; не поворачивать. Кнопки Вдоль / Поперёк ставят объект вдоль линии или перпендикулярно ей. В углу копия стоит по рельсу, а не по биссектрисе. Замкнутый контур: копии лицом наружу или внутрь, как бы контур ни был нарисован; на незамкнутом пути строка погашена.

5Поручень

Галочка Поручень вдоль пути протягивает профиль по тому же пути:

  • Сечение — прямоугольное или круглое, ширина и высота;
  • Привязка — по центру линии, целиком наружу или внутрь;
  • Поднять — выводит поручень на высоту стоек;
  • Продлить концы — за крайние точки пути.

Углы режутся митрой — поворот проходит одной деталью без щелей. Поручень строится вместе с копиями и отменяется тем же Ctrl+Z; можно построить и без копий.

6Доводка

Клик по уже поставленной копии доворачивает её на заданный угол (по умолчанию 90°), Shift+клик — обратно. Доворот сохраняется при смене любых настроек; Сбросить в панели вернёт общую ориентацию. Разброс — случайные поворот, масштаб и сдвиг в заданных пределах; одно и то же зерно даёт тот же результат.
