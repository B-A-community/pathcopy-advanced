PathCopy Advanced 1.0 — quick guide

SketchUp 2024 / 2025 extension: copy groups and components along a path and sweep a railing profile along the same path

1Installation

SketchUp → Window → Extension Manager → Install Extension → choose pathcopy-advanced-1.0.0-eng.rbz → restart SketchUp. Two buttons appear on the "PathCopy Advanced" toolbar — the tool and the settings panel — plus the Extensions → PathCopy Advanced menu. The build is unsigned: under Extension Manager → Settings the loading policy must be "Unrestricted".

2Copy along a path

  1. Start the tool. The settings panel opens with it.
  2. Click an edge — that is the path. Neighbouring edges are picked up automatically, no welding needed; the walk stops at a junction. Clicking a face takes its outline. Ctrl+click adds another path; pre-selecting the edges works too.
  3. Click the group or component to copy. Ctrl+click several objects — the copies will alternate.
  4. Change anything in the panel — the copies rebuild in place. The whole session is a single undo step.

3Distribution

Spacinga fixed distance; the leftover goes to the start, the centre or the end
Countexactly N copies over the whole length
Fit spacingthe nearest spacing to the given one that divides the path evenly
Fit per segmenta copy on every vertex, spacing fitted inside each segment — for railings
Verticesone copy per vertex of the path

In the SketchUp measurement box: 1200 is the spacing in model units, 20x is twenty copies, 0 is one per vertex. Tab is the next mode.

4Orientation

Follow path, in plan — turn by heading; in 3D — tilt with the slope; path plane — for a loop drawn on a wall; keep orientation. The Along / Across buttons set the object along the line or perpendicular to it. At a corner a copy stands square to the rail, not on the bisector. Closed path: copies face outward or inward, however the loop was drawn; on an open path the row is greyed out.

5Railing

The Railing along the path checkbox sweeps a profile along the same path:

  • Section — rectangular or round, width and height;
  • Alignment — centred on the line, wholly outward or inward;
  • Raise — lifts the railing to the top of the posts;
  • Extend the ends — past the end points of the path.

Corners are mitred — a turn is a single piece with no gaps. The railing is built together with the copies and undone by the same Ctrl+Z; it can be built without copies too.

6Finishing by hand

Click a placed copy to turn it by the given angle (90° by default), Shift+click turns it back. The turn survives any change of settings; Clear in the panel restores the common orientation. Randomise — random rotation, scale and shift within the given bounds; the same seed gives the same result.

7Keys

Tabdistribution mode
↑ ↓orientation
← →where the leftover goes
Escone step back; removes the copies first
Right-clickall options, if the panel is closed

Note. Copies inherit the source's material, tag and scale. The tool binds no letter keys — in SketchUp a bare letter goes to your own shortcut. Settings are remembered; the second button reopens a closed panel. Version and authors — Extensions → PathCopy Advanced → About…
